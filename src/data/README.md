# Country boundaries

`gulf-countries.json` contains the United Arab Emirates, Saudi Arabia, Qatar and Oman polygons extracted from `world-atlas@2.0.2/countries-10m.json`, converted with `topojson-client@3.1.0` and rounded to five decimal places. Source: Natural Earth 1:10m administrative boundaries (public domain); world-atlas packaging is ISC licensed.

This approximate country suggestion is computed in the browser after geolocation permission. It is not an address validator, delivery guarantee or authoritative political boundary. Coordinates are neither sent to the application nor stored. Customers can override the suggestion. Checkout still validates a UAE delivery address.
